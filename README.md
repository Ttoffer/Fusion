# Science — Solar fusion (HTML)

This folder contains a **single static web page**, `index.html`, that explains **how the Sun fuses hydrogen into helium** and how that relates to **energy release** and **terrestrial fusion** research.

## What the page covers

- **Proton–proton chain** — the weak interaction step (**W** boson, **u → d**), deuterium formation, and the main **pp I** branch (**²H**, **³He**, **⁴He**).
- **Where the energy comes from** — **mass defect**, **E = Δm c²**, photons, particle motion, and **neutrinos**.
- **Reader-friendly extras** — optional **motion** via **on/off switches** (graphic toggles): cartoon strips under several fusion diagrams, plus an **in-place animation** on the **deuterium–tritium** figure; **order-of-magnitude facts** (neutrino flux, positrons, mass loss, etc.).
- **Fusion reactors on Earth** — how **magnetic confinement** (e.g. **tokamak**) differs from the Sun (including a **Sun vs tokamak** comparison with side labels and a key), **D–T** as the main reactor candidate, main **engineering challenges**, and brief notes on **stellarators**, **inertial confinement**, and other concepts. Tokamak figures include **subtle SVG motion** (plasma circulation) where noted in the page.

The page uses **British English** and simple **SVG figures**; no build step or server is required.

## How to view

Open `index.html` in any modern web browser, or publish the folder on **GitHub Pages** and open the site URL.

**iPhone / iPad:** In Safari, tap **Share → Add to Home Screen**. The **apple-touch-icon** (180×180) is used for the home-screen tile; the short name under the icon comes from **Solar fusion** (`apple-mobile-web-app-title`). The same **apple-touch-icon** asset also appears **in the page header** next to the Hal AI by CJF logo.
